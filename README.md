# V. Balayoghi — Developer Portfolio

A modern, responsive portfolio showcasing full-stack development and Android development skills. Built with semantic HTML5 and optimized CSS with refined typography.

## 🚀 Features

- **Modern Design**: Dark theme with accent gradient colors
- **Responsive**: Optimized for desktop, tablet, and mobile devices
- **Performance**: Lightweight, single-file static HTML
- **Accessibility**: Semantic HTML structure
- **Type System**: Professional typography scale with custom CSS variables
- **Interactive Elements**: Smooth animations and hover effects

## 📋 Sections

- **Hero**: Introduction and call-to-action
- **Skills**: Technical competencies with proficiency indicators
- **Projects**: Portfolio of completed work
- **Awards**: Achievements and recognitions
- **Experience**: Work history and timeline
- **Education**: Qualifications and training
- **Contact**: Multiple ways to get in touch

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (DM Sans, DM Serif Display)

## 📦 Deployment

### Vercel (Recommended)

```bash
vercel deploy
```

The `vercel.json` configuration file handles static serving and routing.

### Local Development

Simply open `port.html` in your browser:

```bash
# On macOS
open port.html

# On Windows
start port.html

# Using Python (any OS)
python -m http.server 8000
```

Then navigate to `http://localhost:8000`
